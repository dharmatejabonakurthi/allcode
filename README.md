# QuickCart - Groceries Delivery Website (Like Zepto)

A modern, fully functional static website for a 10-minute groceries delivery service, built with Python.

## Features

- ⚡ **10-minute delivery promise** - Lightning fast delivery
- 🛒 **Interactive shopping cart** - Add/remove items, update quantities
- 🔍 **Search functionality** - Find products instantly
- 📱 **Fully responsive** - Works on mobile, tablet, and desktop
- 💾 **Local storage cart** - Cart persists across page refreshes
- 🎨 **Modern UI** - Clean design with smooth animations
- 📦 **Product catalog** - 12+ products across categories
- 🔄 **Category filtering** - Browse by product type

## Tech Stack

- **Backend:** Python 3 (HTTP server - standard library only)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Icons:** Font Awesome 6
- **Fonts:** Google Fonts (Inter)
