
# PureSpiral - Spirulina Business Website

A modern, responsive static website for a Spirulina superfood business built with Node.js.

## Features

- 🚀 Pure Node.js HTTP server (no external dependencies)
- 📱 Fully responsive design
- 🎨 Modern, clean UI with smooth animations
- 🛍️ Product showcase with "Add to Cart" functionality
- 📧 Newsletter subscription form
- 🧭 Smooth scrolling navigation
- 🔍 SEO-friendly structure
